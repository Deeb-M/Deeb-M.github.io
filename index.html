Scryx

Focused Web Reconnaissance CLI

Scryx is a lightweight command-line reconnaissance tool built for authorized web security work. It combines bounded crawling, URL analysis, Recon Intelligence, a route-level Recon Map, HTTP checks, scope controls, and structured reporting in a simple workflow designed for Kali Linux and terminal-based security testing.

Python Kali Linux CLI Reconnaissance GitHub Actions MIT License
Current release v1.1.2
⌕

Bounded Crawling

Same-host crawling with controlled depth, page limits, request delays, and conservative defaults.

▤

Recon Intelligence

Combines URL analysis with factual recon leads, suggested next steps, and a route-level Recon Map.

↗

HTTP Checks

Performs bounded status and redirect checks and reports broken or failed requests.

≡

Scope Controls

Restricts reconnaissance by host, path prefix, excluded paths, and file extensions.

▥

Professional Reports

Creates JSON, CSV, and human-readable TXT reports with timestamped scan bundles.

◇

Safe Defaults

External hosts are not crawled, redirect scope is enforced, and request limits remain bounded.
